# Roadmap: v2 (Expansion Plan)

Tài liệu này vạch ra lộ trình phát triển cho phiên bản v2 của `speckit-ai`, tập trung vào sức mạnh tự động hóa bằng AI và khả năng đáp ứng các quy mô dự án đa dạng hơn.

---

## 🎯 Phase 1 — Multi-Language Support & Monorepo

**Mục tiêu:** Mở rộng ra ngoài hệ sinh thái JavaScript, bao phủ các stack phổ biến nhất và hỗ trợ các dự án lớn.

- **Tính năng 1: Monorepo Detection**
  - Nâng cấp `detector.js` quét sâu hơn để nhận diện cấu trúc Monorepo (Lerna, Nx, Turborepo hoặc Yarn Workspaces).
  - Sinh docs độc lập cho từng sub-package (ví dụ: `apps/web` là Next.js, `packages/api` là NestJS), nhưng vẫn giữ chung một chuẩn quy trình SDD ở root.
- **Tính năng 2: Hỗ trợ Python & Go**
  - Quét `requirements.txt` / `Pipfile` / `pyproject.toml` để nhận diện **Django** hoặc **FastAPI**.
  - Quét `go.mod` để nhận diện **Gin** hoặc **Go Fiber**.
  - Thêm hệ thống templates Best Practices mặc định cho Python và Go.

---

## 🎯 Phase 2 — Custom Templates Configuration

**Mục tiêu:** Cho phép người dùng tùy biến nội dung Best Practices.

- **Tính năng: Cấu hình `.speckitrc` (hoặc `speckit.config.json`)**
  - Hỗ trợ file cấu hình ở thư mục gốc của project hoặc thư mục gốc của user (VD: `~/.speckitrc`).
  - Cho phép trỏ tới một thư mục templates local, giúp lập trình viên sử dụng bộ template chuẩn riêng thay vì template mặc định của npm.

---

## 🎯 Phase 3 — Auto-Complete Mode (LLM API Integration)

**Mục tiêu:** Tự động hóa hoàn toàn việc phân tích code (thay thế cờ `--mode=existing` hiện tại), loại bỏ hoàn toàn thao tác copy-paste của con người. (Đây là Killer-Feature của v2).

- **Tính năng 1: LLM Core Integration**
  - Tích hợp gọi API của OpenAI / Anthropic / Google Gemini vào CLI.
  - Nhận khóa API qua biến môi trường: `export OPENAI_API_KEY=...` hoặc đọc từ `.env`.
- **Tính năng 2: Chế độ `--mode=auto`**
  - Khi chạy `npx speckit-ai --mode=auto`, CLI sẽ tự động quét qua toàn bộ cấu trúc thư mục và các file code quan trọng (áp dụng giới hạn token/chunking hợp lý).
  - Tự động gọi API của LLM để phân tích ngữ cảnh dự án.
  - Tự động điền 100% nội dung thực tế (Tech Stack, Code Structure, Error Handling Pattern...) vào các file tài liệu mà không cần sinh ra `AI-PROMPT` markers chờ người dùng thủ công xử lý nữa.
- **Tính năng 3: Git Hook Auto-Sync (Tùy chọn)**
  - Tích hợp hook `pre-commit`. Mỗi khi có sự thay đổi lớn trong cấu trúc dự án hoặc cài đặt thư viện mới, CLI có thể tự động trigger một tác vụ nền để cập nhật lại `structure.md` và `technology.md`.
