# Roadmap: v3 (Enterprise Architecture & Workflow Generators)

> Mục tiêu của v3 là biến `speckit-ai` thành một công cụ quản lý tài liệu kỹ thuật chuẩn mực (Enterprise Standard) bằng cách bổ sung các Artifacts cốt lõi (ADR, Contracts) và nâng tầm Trải nghiệm Lập trình viên (DevEx) thông qua CLI Generators.

---

## Phase 1: Enterprise Architecture (ADRs & Contracts)
Các hệ thống lớn cần lưu trữ quyết định kiến trúc và giao kèo API một cách có hệ thống.
- [ ] **ADR (Architecture Decision Records)**: Bổ sung thư mục `docs/adrs/` và file template `docs/adrs/0000-template.md` (chuẩn MADR - Markdown Any Decision Record) để lưu trữ các quyết định kỹ thuật lớn.
- [ ] **API Contracts**: Bổ sung thư mục `specs/contracts/` để lưu trữ tài liệu giao kèo giữa Frontend & Backend hoặc giữa các Microservices.
- [ ] Cập nhật logic Scaffold mặc định để luôn sinh ra các thư mục và template này khi khởi tạo dự án mới.

## Phase 2: CLI Workflow Generators
Thay vì bắt lập trình viên phải copy-paste template bằng tay (dễ sai sót và tốn thời gian), `speckit-ai` sẽ cung cấp các bộ lệnh (Generators) tương tự như `nest g` hay `ng generate`.
- [ ] **Lệnh tạo Feature Spec**: `speckit-ai generate feature "Payment Gateway"`
  - Tự động tạo thư mục `specs/features/payment-gateway/`.
  - Copy `_template.md` vào thư mục mới và đổi tên thành `spec.md`.
  - Tự động điền tiêu đề và timestamp vào file.
- [ ] **Lệnh tạo ADR**: `speckit-ai generate adr "Use Redis for Cache"`
  - Tự động quét thư mục `docs/adrs/` để tìm ID tiếp theo (VD: từ `0001` lên `0002`).
  - Tạo file `0002-use-redis-for-cache.md` dựa trên template.
- [ ] **Lệnh tạo Contract**: `speckit-ai generate contract "User Service API"`
  - Tạo file `specs/contracts/user-service-api.md`.
