# Phiên bản v1.0.0 (The Enterprise SDD Release)

Dựa trên triết lý từ cuốn "Spec Driven Development", phiên bản v1.0.0 sẽ mang tới các quy trình làm việc mạnh mẽ nhất cho đội ngũ Engineering.

## Mục tiêu (Goal)
Hoàn thiện bộ khung `speckit-ai` trở thành giải pháp toàn diện cho vòng đời phát triển phần mềm bằng AI: Từ lúc lên ý tưởng -> Viết Spec -> Tách Task -> Phê duyệt -> Archive.

## Tính năng sẽ triển khai (Features)

### 1. OpenSpec Workflow (Quản lý thay đổi song song) - Ưu tiên Cao nhất
- **Vấn đề:** Hiện tại khi team thêm một Use Case mới, dev sinh file trực tiếp vào `specs/features/`. Việc này làm xáo trộn "baseline" (sự thật đang chạy trên production) khi feature đó chưa được release.
- **Giải pháp:** Áp dụng mô hình OpenSpec.
- **Commands bổ sung:**
  - `npx speckit-ai propose "Tên tính năng"`: Tạo ra một folder cô lập tại `changes/ten-tinh-nang/` chứa `proposal.md`, `delta-specs.md` và `tasks.md`. Mọi thảo luận và dev sẽ dựa trên thư mục này.
  - `npx speckit-ai archive "Tên tính năng"`: Sau khi code đã được merge và deploy lên production, chạy lệnh này để gộp (merge) phần `delta-specs.md` vào thư mục `specs/` (baseline chính), đồng thời chuyển `changes/ten-tinh-nang/` vào thư mục `archive/` để lưu lịch sử.

### 2. Sinh cấu trúc Test bám sát Acceptance Criteria (Test-Protected)
- **Vấn đề:** Dev lười viết test hoặc AI tự viết test không bám vào Spec.
- **Giải pháp:** Cung cấp lệnh `npx speckit-ai generate tests "UC-XXX"`.
- **Cơ chế:** CLI sẽ đọc file Spec `UC-XXX.md`, móc ra toàn bộ các thẻ `### AC-1`, `### AC-2` và tự động sinh ra một file test skeleton (hoặc gọi LLM để viết luôn mã Test) bám sát tuyệt đối 1-1 với AC.

### 3. Strict Traceability (Tùy chọn)
- **Vấn đề:** Việc truy vết từ Code về Spec rất khó nếu commit message không chứa ID của Use Case.
- **Giải pháp:** Cập nhật Git pre-commit hook.
- **Cơ chế:** Cho phép config trong `.speckit-ai.json` cờ `"requireCommitPrefix": true`. Nếu bật, Git Hook sẽ soi nội dung commit message, nếu không có cấu trúc kiểu `(UC-XXX)` hoặc `(BR-XXX)` thì sẽ cảnh báo. (Tính năng này được tắt mặc định để không gây phiền nhiễu cho các team nhỏ).
